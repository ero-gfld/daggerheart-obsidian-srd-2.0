# Invigoration

***[Level 10](../core_rules/Domains.md#DOMAIN%20CARDS)*** *[Splendor](../domains/Splendor.md) [Spell](../core_rules/Domains.md#DOMAIN%20CARDS).* ***[Recall Cost](../core_rules/Domains.md#DOMAIN%20CARDS)*** *3.*

When you or an ally within [Close](../core_rules/Core%20Mechanics.md#MAPS,%20RANGE,%20AND%20MOVEMENT) range has used a feature that has an exhaustion limit (such as once per rest or once per session), you can **spend any number of [Hope](../core_rules/Core%20Mechanics.md#HOPE%20&%20FEAR)** and roll that many **d6s**. If any roll a 6, the feature can be used again.

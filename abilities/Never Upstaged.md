# Jamais éclipsé

*(VO : Never Upstaged)*

***[Niveau 6](../core_rules/Domains.md#CARTES%20DE%20DOMAINE)*** *[Capacité](../core_rules/Domains.md#CARTES%20DE%20DOMAINE) de [Grâce](../domains/Grace.md).* ***[Coût de rappel](../core_rules/Domains.md#CARTES%20DE%20DOMAINE)*** *2.*

Quand une attaque vous fait marquer 1 [Point de vie](../core_rules/Core%20Mechanics.md#POINTS%20DE%20VIE%20ET%20SEUILS%20DE%20D%C3%89G%C3%82TS) ou plus, vous pouvez **marquer un [Stress](../core_rules/Core%20Mechanics.md#STRESS)** pour placer un nombre de jetons égal au nombre de Points de vie perdus sur cette carte. Lors de votre prochaine attaque réussie, gagnez un bonus de +5 à votre [jet de dégâts](../core_rules/Core%20Mechanics.md#ATTAQUER) pour chaque jeton sur cette carte, puis retirez tous les jetons.

# Chair d’outre-monde

*(VO : Eldritch Flesh)*

***[Niveau 8](../core_rules/Domains.md#CARTES%20DE%20DOMAINE)*** *[Sort](../core_rules/Domains.md#CARTES%20DE%20DOMAINE) d’[Effroi](../domains/Dread.md).* ***[Coût de rappel](../core_rules/Domains.md#CARTES%20DE%20DOMAINE)*** *1.*

Gagnez un bonus de +1 à vos [seuils de dégâts](../core_rules/Core%20Mechanics.md#POINTS%20DE%20VIE%20ET%20SEUILS%20DE%20D%C3%89G%C3%82TS) pour chaque [Stress](../core_rules/Core%20Mechanics.md#STRESS) que vous avez marqué.

De plus, lorsque vous lancez des dés avec la [Peur](../core_rules/Core%20Mechanics.md#ESPOIR%20ET%20PEUR), vous pouvez **dépenser 2 [Espoir](../core_rules/Core%20Mechanics.md#ESPOIR%20ET%20PEUR)** pour effacer un [emplacement d’armure](../core_rules/Equipment.md#ARMURE).

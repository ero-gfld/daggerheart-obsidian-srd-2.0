# Dire Strike

***[Level 5](../core_rules/Domains.md#DOMAIN%20CARDS)*** *[Dread](../domains/Dread.md) [Spell](../core_rules/Domains.md#DOMAIN%20CARDS).* ***[Recall Cost](../core_rules/Domains.md#DOMAIN%20CARDS)*** *2.*

When a target marks any number of [Hit Points](../core_rules/Core%20Mechanics.md#HIT%20POINTS%20&%20DAMAGE%20THRESHOLDS) from an attack you make, you can **spend a [Hope](../core_rules/Core%20Mechanics.md#HOPE%20&%20FEAR)** to drain power from them. The [GM](../core_rules/Introduction.md#WHAT%20IS%20DAGGERHEART%3F) loses a [Fear](../core_rules/Core%20Mechanics.md#HOPE%20&%20FEAR).

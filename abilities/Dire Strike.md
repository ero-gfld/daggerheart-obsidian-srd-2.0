# Dire Strike

***Level 5*** *[Dread](../domains/Dread.md) Spell.* ***[Recall Cost](../core_rules/Domains.md#DOMAIN%20CARDS)*** *2.*

When a target marks any number of [Hit Points](../core_rules/Core%20Mechanics.md#HIT%20POINTS%20&%20DAMAGE%20THRESHOLDS) from an attack you make, you can **spend a [Hope](../core_rules/Core%20Mechanics.md#HOPE%20&%20FEAR)** to drain power from them. The GM loses a Fear.

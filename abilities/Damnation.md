# Damnation

***[Level 9](../core_rules/Domains.md#DOMAIN%20CARDS)*** *[Dread](../domains/Dread.md) [Spell](../core_rules/Domains.md#DOMAIN%20CARDS).* ***[Recall Cost](../core_rules/Domains.md#DOMAIN%20CARDS)*** *2.*

Make a **[Spellcast Roll](../core_rules/Core%20Mechanics.md#SPECIAL%20ROLLS)** against a target within [Far](../core_rules/Core%20Mechanics.md#MAPS,%20RANGE,%20AND%20MOVEMENT) range. On a success, **mark any number of [Stress](../core_rules/Core%20Mechanics.md#STRESS)** to roll an equal number of **d20s**, dealing [magic damage](../core_rules/Core%20Mechanics.md#ATTACKING) equal to the total result. If this attack defeats the target, all [adversaries](../core_rules/Using%20Adversaries.md) within Far range of the target must mark a Stress.

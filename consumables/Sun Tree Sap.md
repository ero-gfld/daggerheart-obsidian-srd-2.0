# Sève de l’arbre-soleil

*(VO : Sun Tree Sap)*

Consommez cette sève pour lancer un d6. Sur un résultat de 5–6, libérez 2 [PV](../core_rules/Core%20Mechanics.md#POINTS%20DE%20VIE%20ET%20SEUILS%20DE%20D%C3%89G%C3%82TS). Sur un résultat de 2–4, évacuez 3 [Stress](../core_rules/Core%20Mechanics.md#STRESS). Sur un résultat de 1, vous traversez le voile de la mort et revenez changé, gagnant une [cicatrice](../core_rules/Core%20Mechanics.md#MORT).

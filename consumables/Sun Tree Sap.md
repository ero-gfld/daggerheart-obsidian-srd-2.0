# Sun Tree Sap

Consume this sap to roll a d6. On a result of 5–6, clear 2 [HP](../core_rules/Core%20Mechanics.md#HIT%20POINTS%20&%20DAMAGE%20THRESHOLDS). On a result of 2–4, clear 3 [Stress](../core_rules/Core%20Mechanics.md#STRESS). On a result of 1, see through the veil of death and return changed, gaining one [scar](../core_rules/Core%20Mechanics.md#DEATH).

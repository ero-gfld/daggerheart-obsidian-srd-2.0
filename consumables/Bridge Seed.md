# Graine de pont

*(VO : Bridge Seed)*

D’épaisses vignes poussent depuis votre position jusqu’à un point de votre choix à portée [Loin](../core_rules/Core%20Mechanics.md#CARTES,%20PORT%C3%89E%20ET%20D%C3%89PLACEMENT), vous permettant de grimper dessus ou de les traverser. Les vignes se dissipent à votre prochain [repos court](../core_rules/Core%20Mechanics.md#TEMPS%20DE%20REPOS).

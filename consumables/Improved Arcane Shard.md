# Éclat arcanique amélioré

*(VO : Improved Arcane Shard)*

Vous pouvez effectuer un jet de [Finesse](../core_rules/Character%20Creation.md#%C3%89TAPE%203) pour lancer cet éclat sur un groupe d’[adversaires](../core_rules/Using%20Adversaries.md) à portée [Loin](../core_rules/Core%20Mechanics.md#CARTES,%20PORT%C3%89E%20ET%20D%C3%89PLACEMENT). Les cibles contre lesquelles vous réussissez subissent 2d20 [dégâts magiques](../core_rules/Core%20Mechanics.md#ATTAQUER).

# Glossaire anglais → français

Le lexique de la traduction française du SRD. Chaque terme de règle n'a qu'une traduction : les traducteurs la reprennent telle quelle, avec la même majuscule.

**Source** : « coffre » = déjà employé dans le coffre de Chénaos (PNJ, adversaires maison, voies d'ascension) ; *proposition* = choix nouveau, à valider.

## Conventions

- **Adresse** : vouvoiement (« vous gagnez 3 Espoir », « Dépensez une Peur »).
- **Typographie** : espace avant `: ; ? !`, « guillemets », apostrophe typographique ’. Pas de tiret cadratin.
- **Majuscules** : les termes de jeu gardent la majuscule de l'anglais (Espoir, Peur, Stress, Évasion, Proche, Vulnérable…). Les termes en minuscules en anglais restent en minuscules (repos long, jet de réaction).
- **Noms propres** (cartes, adversaires, objets, armes, armures, environnements) : traduits. Le nom anglais reste dans le nom du fichier, en alias et entre parenthèses sous le titre : `*(VO : A Soldier’s Bond)*`.
- **Chiffres et dés** : inchangés (`1d12+2`, `+3`, `8/15`). `phy` et `mag` restent tels quels dans les profils (coffre).
- **Liens** : le texte du lien est traduit, la cible `(...)` ne change jamais.

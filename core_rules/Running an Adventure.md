# Running an Adventure

## INTRODUCTION

The [GM](Introduction.md#WHAT%20IS%20DAGGERHEART%3F) is responsible for guiding the narrative and roleplaying the world the [PCs](Introduction.md#WHAT%20IS%20DAGGERHEART%3F) inhabit. This section provides you with advice for running Daggerheart: using the core mechanics; creating memorable encounters; planning exciting sessions; selecting, creating, and using [GM moves](Making%20Moves.md); crafting a full campaign; running dynamic [NPCs](Making%20Moves.md#RUNNING%20GM%20NPCS); and more.

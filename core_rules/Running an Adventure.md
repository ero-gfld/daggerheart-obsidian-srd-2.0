# Mener une aventure

*(VO : Running an Adventure)*

## INTRODUCTION

Le [MJ](Introduction.md#QU%E2%80%99EST-CE%20QUE%20DAGGERHEART%20%3F) a la charge de guider le récit et d’incarner le monde où vivent les [PJ](Introduction.md#QU%E2%80%99EST-CE%20QUE%20DAGGERHEART%20%3F). Cette section vous donne des conseils pour mener Daggerheart : utiliser les mécaniques de base ; créer des rencontres mémorables ; préparer des séances palpitantes ; choisir, créer et utiliser les [actions du MJ](Making%20Moves.md) ; construire une campagne complète ; faire jouer des [PNJ](Making%20Moves.md#FAIRE%20JOUER%20LES%20PNJ%20DU%20MJ) dynamiques ; et plus encore.

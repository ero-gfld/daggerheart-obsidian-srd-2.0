# Gardien du savoir

*(VO : Lorekeeper)*

Vous pouvez consigner le nom et les détails de jusqu’à trois créatures hostiles dans ce livre. Vous gagnez un bonus de +1 aux [jets d’action](../core_rules/Core%20Mechanics.md#JETS%20D%E2%80%99ACTION) contre ces créatures.

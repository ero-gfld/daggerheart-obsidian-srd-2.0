# Amulette insaisissable

*(VO : Elusive Amulet)*

Une fois par [repos long](../core_rules/Core%20Mechanics.md#TEMPS%20DE%20REPOS), vous pouvez activer cette amulette pour devenir *[Caché](../core_rules/Core%20Mechanics.md#%C3%89TATS%20STANDARD)* jusqu’à ce que vous vous déplaciez. Tant que vous êtes *Caché* de cette façon, vous restez invisible, même si un [adversaire](../core_rules/Using%20Adversaries.md) se déplace jusqu’à l’endroit où il vous verrait normalement.

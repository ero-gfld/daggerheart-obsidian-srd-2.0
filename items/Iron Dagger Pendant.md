# Pendentif de dague de fer

*(VO : Iron Dagger Pendant)*

Une fois par [repos long](../core_rules/Core%20Mechanics.md#TEMPS%20DE%20REPOS), vous pouvez dépenser un [Espoir](../core_rules/Core%20Mechanics.md#ESPOIR%20ET%20PEUR) pour confier au pendentif le nom d’une créature. Le pendentif vous attire doucement vers la position actuelle de cette créature jusqu’à votre prochain repos long.

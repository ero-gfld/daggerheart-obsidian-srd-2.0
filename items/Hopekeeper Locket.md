# Médaillon du Gardien de l’Espoir

*(VO : Hopekeeper Locket)*

Pendant un [repos long](../core_rules/Core%20Mechanics.md#TEMPS%20DE%20REPOS), si vous avez 6 [Espoir](../core_rules/Core%20Mechanics.md#ESPOIR%20ET%20PEUR), vous pouvez dépenser un Espoir pour imprégner ce médaillon de votre résolution généreuse. Lorsque vous avez 0 Espoir, vous pouvez utiliser le médaillon pour gagner immédiatement un Espoir. Le médaillon doit être imprégné à nouveau avant de pouvoir être utilisé de cette façon.

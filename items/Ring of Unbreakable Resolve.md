# Anneau de résolution inébranlable

*(VO : Ring of Unbreakable Resolve)*

Une fois par session, quand le [MJ](../core_rules/Introduction.md#QU%E2%80%99EST-CE%20QUE%20DAGGERHEART%20%3F) dépense une [Peur](../core_rules/Core%20Mechanics.md#ESPOIR%20ET%20PEUR), vous pouvez dépenser 4 [Espoir](../core_rules/Core%20Mechanics.md#ESPOIR%20ET%20PEUR) pour annuler les effets de cette Peur dépensée.
